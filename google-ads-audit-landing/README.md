# Google Ads Audit Landing Page

A React + TypeScript + Vite landing page for a free Google Ads audit offer, styled after high-conversion "workshop"-style funnel pages (bold dark theme, gold accent, benefit-driven copy).

## Before going live

- Replace `CALENDLY_URL` in `src/content.ts` with your real Calendly scheduling link.
- Replace the placeholder entries in `TESTIMONIALS` (`src/content.ts`) with real client testimonials once available.
- Update `BRAND_NAME` in `src/content.ts` if needed.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
